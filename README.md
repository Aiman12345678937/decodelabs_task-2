# Expense Tracker (Python)

Simple CLI Expense Tracker program jo user se expenses leta hai, unko add karta hai, aur final total show karta hai.

## 🎯 Features
- User input expenses
- Running total (accumulator pattern)
- Input validation (no crash on wrong input)
- Exit using "quit"
- Final total display

## ⚙️ How to Run
```bash
python expense_tracker.py
